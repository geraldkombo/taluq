## Product Name (SEO)
Taluq Chat Wallet | Zero Fee Omni Settlement | Solana

## One-liner
Taluq is a chat wallet for Kenya: zero fee transfers, remittances, and omni settlement on Solana.

## Boilerplate (Copy/Paste)
Taluq is a Kenya-first Chat Wallet that makes money movement feel instant, private, and zero-fee. Users link a phone number (no seed phrases), receive a Global Receive link for diaspora, and execute everyday actions by chat commands like “balance”, “send”, “receive”, and “deposit”. Taluq uses Paystack for regulated fiat rails and Solana for low-latency settlement.
